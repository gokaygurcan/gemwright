`@gemwright/client` serves a browser client that connects to an Ultima Online server. It runs on its own, next to a Gemwright server or any compatible one. `gemwright shard deploy --client` deploys it for you.

To run it directly, with Bun 1.4.3 or newer:

```sh
npm install @gemwright/client
cd node_modules/@gemwright/client
UO_HOST=127.0.0.1 GAMEFILES_PATH=/path/to/gamefiles bun bundle/server.js
```

| Variable | Default | Meaning |
| --- | --- | --- |
| `UO_HOST` | required | Server endpoint |
| `GAMEFILES_PATH` | required | Game-file directory with its manifest |
| `UO_PORT` | `2593` | Server port |
| `UO_CLIENT_VERSION` | `7.0.45.1` | Client version |
| `UO_ENCRYPTION` | `0` | Encryption mode, 0-5 |
| `SERVER_NAME` | `Gemwright` | Display name |
| `PUBLIC_ORIGIN` | | Public HTTPS origin; required on Railway |
| `CLIENT_BUNDLE_PATH` | `bundle/public` | Browser payload directory |
| `CLIENT_LISTEN_HOST` | `::` | Listen address |
| `PORT` | `3000` | HTTP port |
