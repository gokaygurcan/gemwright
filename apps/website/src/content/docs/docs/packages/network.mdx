`@gemwright/network` speaks the Ultima Online protocol as a client: packet framing and compression, login, characters, movement, gumps, trade and commerce, and observation of the world around a player. [AI residents](/docs/packages/ai/) use it to play. It is a private library.

```ts
import { PlayerSession } from "@gemwright/network";
```
