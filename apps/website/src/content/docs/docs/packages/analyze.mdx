`@gemwright/analyze` reads ServUO world saves into a terminal report or a browsable site of characters, items and mobiles. It is private and runs from a repository clone; see [Analyze world saves](/docs/guides/analyze/).

| Command | Options |
| --- | --- |
| `bun dist/src/index.js` | `--saves`, `--output`, `--character`, `--json` |
| `bun dist/src/serve.js` | `--shard`, `--local`, `--files`, `--port` (default `4100`) |
