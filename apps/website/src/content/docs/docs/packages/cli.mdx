`@gemwright/cli` owns the commands: [`gemwright init`](/docs/reference/cli/init/) and [`gemwright shard`](/docs/reference/cli/shard/). It composes every other package and carries the server, client and AI builds it was released with.

```sh
npm install --global @gemwright/cli
gemwright-cli --help
```

Installing [`gemwright`](/docs/packages/gemwright/) is the usual way; this package provides the `gemwright-cli` bin. Requires Node.js 24 or newer.
