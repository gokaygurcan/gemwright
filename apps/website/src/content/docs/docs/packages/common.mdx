`@gemwright/common` holds what other packages share: the [`gemwright.json`](/docs/reference/configuration/) schema and validation, component compatibility rules, game data (bodies, items, skills, maps, regions, expansions) and readers for client assets. It is a private, runtime-neutral library.

```ts
import { emulators } from "@gemwright/common/config/shard";
```
