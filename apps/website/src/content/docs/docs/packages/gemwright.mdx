The `gemwright` package is the command you install or run with `npx`. It runs the exact matching version of [`@gemwright/cli`](/docs/packages/cli/) in the same process, keeping signals and exit codes.

```sh
npm install --global gemwright
gemwright --help
```

Requires Node.js 24 or newer. See the [CLI reference](/docs/reference/cli/).
